# clip2pdf — クリップボードの図を PDF にして保存するアプリ

使い方は2通りです。

- **ペースト**: Keynote で図を選んで **⌘C**、このアプリに切り替えて **⌘V**
- **ドロップ**: **`.key` ファイルや PDF をウィンドウに落とす**（Dock アイコンへのドロップ、
  Finder の「このアプリケーションで開く」、⌘O でも同じ）

どちらも余白を落とした PDF として保存します。ドロップした場合はコマンドライン版の
`key2pdf` / `pdftrim` と同じことを、アプリだけで済ませられます。

## 取り出し方は2通り

**Keynote はクリップボードに PDF を載せません。**実際に載るのは PNG / TIFF（図の実寸の
2倍 = 144dpi、背景は透明）と iWork の独自形式だけです。そのため取り出し方を2つ用意しました。

| 取り出し | 中身 | 背景 | かかる時間 | 必要な許可 |
| --- | --- | --- | --- | --- |
| **ベクタ（Keynote 経由）** | ベクタのまま（拡大しても劣化しない） | Keynote のテーマの地色（白） | 4秒ほど | オートメーション＋**アクセシビリティ** |
| **画像** | 144dpi のラスタ | **透明のまま**（白も選べる） | 即時 | なし |

ベクタ側は、クリップボードの中身を**一時的な Keynote 書類に貼り直して PDF に書き出して**
います（貼り付けに ⌘V を送るため、アクセシビリティの許可が要ります）。許可がない場合は
その旨を表示して画像として取り込みます。

TeX の図なら **ベクタ** を、色の付いた背景に重ねるなど透明が要るなら **画像** を選んで
ください。

## ビルドと起動

```sh
./app/build.sh                      # → app/build/clip2pdf.app
open app/build/clip2pdf.app
```

Xcode（または Command Line Tools）の `swiftc` だけでビルドできます。
**外部ライブラリは使いません**（Ghostscript も Node も Ruby も不要）。
よく使うなら `app/build/clip2pdf.app` をアプリケーションフォルダへ移してください。

## 使い方

**ペーストする場合**

1. Keynote で図を選んで ⌘C
2. clip2pdf に切り替えて ⌘V
3. プレビューと「変換前 → 変換後」の寸法を確認して **保存**

**ファイルをドロップする場合**

`.key` / PDF / 画像をウィンドウに落とすと、**その場で変換して保存**します（確認は不要）。

- `.key` → Keynote に PDF を書き出させて、スライドごとに余白を落とす（`key2pdf` と同じ）
- PDF → 各ページの余白を落とす（`pdftrim` と同じ）
- 複数ページは既定で **1ページ1ファイル**（`名前-01.pdf`, `-02.pdf` …）に分けます
- 出力は既定で**元ファイルと同じ場所**。名前も元ファイル名を引き継ぎます
- 何枚もまとめて落とせます

| 項目 | 説明 |
| --- | --- |
| 余白をトリミング | 切り抜きの ON/OFF（既定: ON） |
| 余白 | 切り抜きに残す余白 pt（既定: 0） |
| しきい値 | 背景とみなす色差 0–255（既定: 8） |
| 取り出し | **ベクタ（Keynote 経由）**（既定）か **画像**。上の表を参照（ペースト時のみ） |
| ページごとに別ファイル | 複数ページを1枚ずつに分ける（既定: ON） |
| 元ファイルの隣に保存 | ドロップしたファイルの横に出力する（既定: ON）。OFF なら下の保存先へ |
| 背景 | **透明**（既定）か **白**。白を選ぶとページ全面に白を敷く（ベクタ経由のときは Keynote の地色が入るため選べません） |
| 保存先 | 保存するフォルダ（既定: デスクトップ） |
| 名前 | `名前-01.pdf`, `-02.pdf` … と連番で保存 |
| ペーストしたら自動で保存 | ON にすると ⌘V だけで保存まで済む |

設定は次回起動時も残ります。設定を変えるとプレビューが即座に追従し、
背景が透明のときはプレビューに市松模様が出ます。

### 背景について

**画像**で取り出した場合、Keynote がクリップボードに載せる PNG は背景が透明なので、
そのまま保存すれば透明の PDF になります。白地が要るとき（図の下に別のものが透けると
困るとき）は「白」を選んでください。

**ベクタ（Keynote 経由）**では、書き出し元が Keynote のスライドになるため、テーマの
地色（通常は白）が必ず入ります。透明にはできません。

また、**もともと白く塗られている図を透明にすることはできません**。塗られた白は図の一部
なので、消すには中身を書き換えることになります。

### アクセシビリティの許可

ベクタで取り出すには、システム設定 > プライバシーとセキュリティ > **アクセシビリティ**で
clip2pdf を許可してください（Keynote への ⌘V に必要）。未許可のときは画面に案内と
「設定を開く」ボタンが出ます。許可しないまま使う場合は「取り出し: 画像」を選んでください。

## 切り抜きの仕組み

（どちらの取り出し方でも共通）

1. ページを Quartz でラスタ化する
2. **塗られている範囲（alpha > 0）**を内容とみなす。Keynote からコピーした図は背景が
   透明なのでこれで足りる
3. ページ全面が塗られていた場合（スライドごと書き出した PDF など）は、四隅から背景色を
   推定して**背景色と異なる画素**の範囲を採る
4. PDFKit でページ矩形（MediaBox / CropBox）をその範囲に付け替える
5. 背景に「白」を選んだときだけ、切り抜いた範囲いっぱいに白を敷いてから書き出す

ページの中身は再描画しないので**ベクタのまま**です。CLI の `key2pdf` / `pdftrim` と
同じ考え方で、同じ入力からは同じ寸法になります（テストで突き合わせています）。

## 画像を貼った場合

クリップボードにベクタ PDF がなければ、TIFF / PNG などの画像を PDF に包んで同じように
扱います。この場合の中身はラスタのままです。

## コマンドラインから

GUI を出さずに動かすモードもあります（テスト用ですが単体でも使えます）。

```sh
BIN=app/build/clip2pdf.app/Contents/MacOS/clip2pdf
$BIN --trim in.pdf out.pdf --margin 2            # ファイルを切り抜く
$BIN --clipboard out.pdf                         # クリップボードの図を切り抜いて保存
$BIN --convert figures.key out/                  # .key をページごとに書き出す（key2pdf 相当）
$BIN --convert paper.pdf out/                    # PDF の余白を落とす（pdftrim 相当）
$BIN --convert paper.pdf out/ --merge            # 1本にまとめる
$BIN --clipboard out.pdf --keynote               # Keynote に貼り戻してベクタで取り出す
$BIN --trim in.pdf out.pdf --background white    # 白地にする
$BIN --trim in.pdf out.pdf --no-trim             # 切り抜かずに PDF 化だけ
```

## 注意

- 署名はアドホックです。初回起動時に macOS が警告を出す場合は、
  システム設定 > プライバシーとセキュリティ から開くことを許可してください。
- Keynote 側で**図形を選んでコピー**してください（スライド一覧ではなく編集画面で選択）。
- `.key` のドロップは Keynote に書き出させるので、**オートメーションの許可**が要ります
  （アクセシビリティは不要）。開いたままの書類を渡した場合は閉じずにそのまま使います。
- ベクタ経由では一時的に Keynote が前面に出ます（新規書類を作って貼り、書き出したら
  保存せずに閉じます）。元の書類には触れません。
- 影やぼかしの付いた図形は、影まで含めた範囲が「内容」になります。
