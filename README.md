# clip2pdf

Keynote の図を、**余白のない PDF** にして保存する macOS アプリです。

TeX の `\includegraphics` に貼る図を作ることを目的にしています。Keynote の書き出しは
「スライド1枚 = 1ページ」なので図の周りにスライドの余白がそのまま残りますが、
clip2pdf は内容のある範囲まで切り詰め、図にぴったり合ったサイズの PDF を作ります。
ページの中身は再描画しないので**ベクタのまま**です。

使い方は2通りです。

- **ペースト**: Keynote で図を選んで **⌘C** → clip2pdf に切り替えて **⌘V**
- **ドロップ**: **`.key` ファイルや PDF をウィンドウに落とす**（Dock アイコンへのドロップ、
  Finder の「このアプリケーションで開く」、⌘O でも同じ）

同じ処理をコマンドラインから行う `key2pdf` / `pdftrim` も同梱しています
（[key2pdf.md](key2pdf.md) / [pdftrim.md](pdftrim.md)）。

## 導入

### ソースからビルドする（推奨）

```sh
git clone https://github.com/sudahiroshi/clip2pdf.git
cd clip2pdf
./app/build.sh                              # → app/build/clip2pdf.app
cp -R app/build/clip2pdf.app /Applications/
open /Applications/clip2pdf.app
```

Xcode（または Command Line Tools）の `swiftc` だけでビルドできます。
**外部ライブラリは使いません**（Ghostscript も Node も Ruby も不要）。
自分でビルドしたアプリは Gatekeeper に止められないので、この方法が一番簡単です。

### Releases から入れる

[Releases](https://github.com/sudahiroshi/clip2pdf/releases) の `clip2pdf.app.zip` を
展開してアプリケーションフォルダへ入れるだけです。Developer ID で署名し Apple の
公証を受けているので、**ダウンロードしてそのまま開けます**。

配布する側の手順は [RELEASING.md](RELEASING.md) にまとめてあります。

## 使い方

### ファイルをドロップする

`.key` / PDF / 画像をウィンドウに落とすと、**その場で変換して保存**します（確認は不要）。

- `.key` → Keynote に PDF を書き出させて、スライドごとに余白を落とす（`key2pdf` と同じ）
- PDF → 各ページの余白を落とす（`pdftrim` と同じ）
- 複数ページは既定で **1ページ1ファイル**（`名前-01.pdf`, `-02.pdf` …）に分けます
- 出力は既定で**元ファイルと同じ場所**。名前も元ファイル名を引き継ぎます
- 何枚もまとめて落とせます

### ペーストする

1. Keynote で図を選んで ⌘C
2. clip2pdf に切り替えて ⌘V
3. プレビューと「変換前 → 変換後」の寸法を確認して **保存**

**Keynote はクリップボードに PDF を載せません。**実際に載るのは PNG / TIFF（図の実寸の
2倍 = 144dpi、背景は透明）と iWork の独自形式だけです。そのため取り出し方を2つ用意しています。

| 取り出し | 中身 | 背景 | かかる時間 | 必要な許可 |
| --- | --- | --- | --- | --- |
| **ベクタ（Keynote 経由）** | ベクタのまま（拡大しても劣化しない） | Keynote のテーマの地色（白） | 4秒ほど | オートメーション＋**アクセシビリティ** |
| **画像** | 144dpi のラスタ | **透明のまま**（白も選べる） | 即時 | なし |

ベクタ側は、クリップボードの中身を**一時的な Keynote 書類に貼り直して PDF に書き出して**
います。許可がない場合はその旨を表示して画像として取り込みます。

TeX の図なら **ベクタ** を、色の付いた背景に重ねるなど透明が要るなら **画像** を選んで
ください。`.key` をドロップする場合は常にベクタで、アクセシビリティの許可も不要です。

## 画面の項目

| 項目 | 説明 |
| --- | --- |
| 余白をトリミング | 切り抜きの ON/OFF（既定: ON） |
| 余白 | 切り抜きに残す余白 pt（既定: 0） |
| しきい値 | 背景とみなす色差 0–255（既定: 8） |
| 取り出し | **ベクタ（Keynote 経由）**（既定）か **画像**（ペースト時のみ） |
| 背景 | **透明**（既定）か **白**（ベクタ経由のときは Keynote の地色が入るため選べません） |
| ページごとに別ファイル | 複数ページを1枚ずつに分ける（既定: ON） |
| 保存先 | 保存するフォルダ（既定: デスクトップ） |
| 元ファイルの隣に保存 | ドロップしたファイルの横に出力する（既定: ON） |
| 名前 | `名前-01.pdf`, `-02.pdf` … と連番で保存 |
| ペーストしたら自動で保存 | ON にすると ⌘V だけで保存まで済む |

設定は次回起動時も残ります。設定を変えるとプレビューが即座に追従し、背景が透明のときは
プレビューに市松模様が出ます。

## 背景について

**画像**で取り出した場合、Keynote がクリップボードに載せる PNG は背景が透明なので、
そのまま保存すれば透明の PDF になります。白地が要るときは「白」を選んでください。

**ベクタ（Keynote 経由）**や `.key` のドロップでは、書き出し元が Keynote のスライドに
なるため、テーマの地色（通常は白）が必ず入ります。透明にはできません。

また、**もともと白く塗られている図を透明にすることはできません**。塗られた白は図の一部
なので、消すには中身を書き換えることになります。

## 必要な許可

- **オートメーション**（`.key` の変換とベクタ取り出しに必要）
  システム設定 > プライバシーとセキュリティ > オートメーション
- **アクセシビリティ**（クリップボードからのベクタ取り出しだけに必要）
  Keynote へ「編集 > ペースト」を送るために使います。未許可のときは画面に案内と
  「設定を開く」ボタンが出ます。許可しないなら「取り出し: 画像」を選ぶか、
  `.key` ファイルをドロップしてください。

アプリを作り直すとアドホック署名が変わるため、許可を取り直す必要が出る場合があります。
Developer ID を持っているなら `SKIP_NOTARIZE=1 ./app/sign.sh` で署名しておくと、
署名が安定するので**作り直しても許可が維持されます**（[RELEASING.md](RELEASING.md) 参照）。

## 切り抜きの仕組み

1. ページを Quartz でラスタ化する
2. **塗られている範囲（alpha > 0）**を内容とみなす。Keynote からコピーした図は背景が
   透明なのでこれで足りる
3. ページ全面が塗られていた場合（スライドごと書き出した PDF など）は、四隅から背景色を
   推定して**背景色と異なる画素**の範囲を採る
4. PDFKit でページ矩形（MediaBox / CropBox）をその範囲に付け替える
5. 背景に「白」を選んだときだけ、切り抜いた範囲いっぱいに白を敷いてから書き出す

ページの中身は再描画しないのでベクタのままです。同梱の `key2pdf` / `pdftrim` と
同じ考え方で、同じ入力からは同じ寸法になります（テストで突き合わせています）。

## コマンドラインから

GUI を出さずに動かすモードもあります。

```sh
BIN=app/build/clip2pdf.app/Contents/MacOS/clip2pdf
$BIN --convert figures.key out/                  # .key をページごとに書き出す
$BIN --convert paper.pdf out/                    # PDF の余白を落とす
$BIN --convert paper.pdf out/ --merge            # 1本にまとめる
$BIN --trim in.pdf out.pdf --margin 2            # ファイル1つを切り抜く
$BIN --clipboard out.pdf                         # クリップボードの図を切り抜いて保存
$BIN --clipboard out.pdf --keynote               # Keynote に貼り戻してベクタで取り出す
$BIN --trim in.pdf out.pdf --background white    # 白地にする
$BIN --trim in.pdf out.pdf --no-trim             # 切り抜かずに PDF 化だけ
```

## 同梱のコマンド

| コマンド | 用途 |
| --- | --- |
| [`key2pdf`](key2pdf.md) | `.key` から、スライドごとに図の部分だけを切り出した PDF を作る |
| [`pdftrim`](pdftrim.md) | できあいの PDF の余白を落とす |

どちらも Node.js 版（リポジトリ直下）と Ruby + AppleScript 版（[`ruby/`](ruby/README.md)）が
あり、使い方と出力は同じです。

## 注意

- Keynote 側で**図形を選んでコピー**してください（スライド一覧ではなく編集画面で選択）。
- ベクタ経由では一時的に Keynote が前面に出ます（新規書類を作って貼り、書き出したら
  保存せずに閉じます）。元の書類には触れません。
- **1スライド1図の運用が前提です。** スライド上の可視要素すべてが切り抜き対象になります。
- 影やぼかしの付いた図形は、影まで含めた範囲が「内容」になります。
- 切り抜きはページ矩形の付け替えなので、矩形の外の内容はファイル内に残ります
  （表示・印刷はされません）。
- 署名はアドホックです。初回起動時に macOS が警告を出す場合は、
  システム設定 > プライバシーとセキュリティ から開くことを許可してください。

## テスト

```sh
./tests/run_tests.sh                   # Keynote もクリップボードも触らない
./tests/run_tests.sh --with-keynote    # Keynote での書き出しも含める
./tests/run_tests.sh --with-clipboard  # クリップボード経由も含める（中身を書き換えます）
```

既知の寸法の PDF を `pdflatex` で作り、**clip2pdf・Node 版・Ruby 版の3つ**について
切り抜き結果の実寸がすべて一致することを確かめます。あわせて `--margin` / ページ指定 /
分割 / `--noise` / 背景 / エラー処理、`\includegraphics` の通りも検証します。
